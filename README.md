This repo contains my notes, code snippets, and mini-projects as I progress through the course.

---

## 🧭 Course Overview

This course dives deep into the world of modern **React development**, starting from the basics and gradually moving into advanced concepts like:

- React Hooks (`useState`, `useEffect`, `useReducer`, `useRef`, etc.)
- Component-driven development
- State management with Context API and Redux
- Routing with React Router
- Working with side effects and HTTP requests
- Custom Hooks, Forms, Animations
- Advanced optimizations & patterns
- React Query and Next.js (including React Server Components)
- Testing, TypeScript, and Deployment
